Open research system · paper / research only

Seven agents. One research memo. Zero live trading.

Sunkara AI Fund is a multi-agent investment research floor. Specialized agents scout opportunities, read technicals, fundamentals, and news, score edge, enforce risk limits, and write a paper memo. Founded by Dineshgopi Sunkara.

View sample analysis Inspect GitHub

This public page is a static showcase. It does not call a live backend or handle real money. The TSLA walkthrough below is bundled demo data from the open-source pipeline.

7-agent architecture

LangGraph orchestrates the floor. Risk can reject a name before a memo is written.

01Market Scout

Finds and ranks opportunities across a universe.

02Technical

RSI, MACD, moving averages, trend, and bias.

03Fundamental

Financials, valuation, and quality checks.

04News

Headlines, catalysts, and sentiment.

05Quant

Edge score, win probability, and scenarios.

06Risk Manager

Stress tests, downside, sizing — can REJECT.

07Portfolio Manager

Final investment memo and paper allocation.

Founder

Founded by Dineshgopi Sunkara

Sunkara AI Fund is an open educational project: a LangGraph pipeline that runs seven research agents and writes a paper memo. It is not a licensed investment adviser, does not manage client capital, does not advertise AUM or returns, and does not execute live trades.

Clone the repo, run the demo without API keys, or attach Anthropic for live-mode enrichment. The source is the product.
